# Python packages the custom nodes and the resource watcher need, on top of

# verified to import on geo-a-node-gb10-2 on 2026-09-21. Test-only packages are in test.txt.
#
# Install with --no-deps so nothing already in the venv, above all the tuned torch,
# gets swapped:
#   .venv/bin/python -m pip install --no-deps -r comfyui/zbrad/requirements/custom-nodes.txt
#
# Left out on purpose: the nvidia-* CUDA library wheels (cublas, cudnn, ...),
# whose PyPI CUDA 13.0 builds could shadow the system CUDA 13.4 the tuned torch
# uses. nvidia-ml-py is NOT one of those: it is a pure-python NVML binding
# (py3-none-any) and it must be installed, because it provides the `pynvml`
# module Crystools' GPU/VRAM monitor needs. Excluding it once left the monitor
# reporting an empty GPU list, so the resource watcher logged no GPU stats.
#
# Four entries below are capped by a dependent, not held back by accident, so do
# not bump them to latest: albucore (albumentations pins ==0.0.24),
# cachebox (deepdiff <6), antlr4-python3-runtime (omegaconf ==4.9.*) and
# pyee (playwright <14). `pip check` catches it if one drifts past its cap.
#
# Grouped by the node that pulls each package in, traced from the installed
# dependency graph.
